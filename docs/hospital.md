# Модель больницы

Отделение → палаты → койки → пациенты → приёмы.

Правила:
- Палата переполнена → запрет госпитализации
- Выписка проставляет cost и status='closed'
- Средний койко-день = discharged - admitted

Отчёты:
- Загрузка коек
- Нагрузка отделений
- Выручка по отделениям
- Выписки за 30 дней
